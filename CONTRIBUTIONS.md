# Contributions

This file summarizes contributions to the software and experimental tools developed for VoxelDiffusionCut.

- **Takumi Hachimine** — Developed the initial codebase and established the experimental pipeline for simple-shaped models.
- **Yuhwan Kwon** — Extended the initial implementation to support complex-shaped models and adapted the code for those experiments.
- **Cheng-Yu Kuo** — Generated the complex-shaped dataset and developed visualization tools for complex-shaped models.
- **Tomoya Yamanokuchi** — Integrated the simple- and complex-shaped workflows into a unified codebase, implemented and refined the algorithmic pipeline, and carried out substantial refactoring and system integration.
